## 1. 项目概述

### 1.1 定位

一个本地运行（无需服务器、无需部署）的加密货币筹码分布筛选工具。面向小资金用户，通过流通率、市值、涨跌幅等维度筛选潜在高赔率标的。

### 1.2 核心功能

- **数据源**：CoinGecko 公开 API（无需 API Key）
- **筛选维度**：
  - 市值范围（$15M ~ $500B）
  - 流通率范围（0% ~ 100%）
  - 24h 最小振幅
  - 7 日最小涨跌幅
- **预设策略**：
  - **Preset A（窒息流）**：市值 $15M~$100M、流通率 0%~30% → 低流通小盘，按流通率升序
  - **Preset B（全流通）**：市值 $15M~$50M、流通率 98%~100% → 全流通小盘，按 7 日涨幅降序
- **量化评分**：star_rating（1~5 星），基于市值排名自动转换（top10=5星，top20=4星……最低1星）
- **资金分配计算器**：等额分配给评分最高的 N 个标的
- **交互特性**：点击表头排序、动量信号行高亮、5 星标的特别标记

### 1.3 技术栈

| 层 | 技术 | 版本 |
|---|---|---|
| 操作系统 | Windows | 10 / 11 |
| 数据获取 | PowerShell 5.1 | 系统内置 |
| 数据 API | CoinGecko | v3（免 Key） |
| 本地服务器 | Python | 3.12.10 |
| 前端 | 原生 JS + CSS（无框架） | ES6+ |
| 网络代理 | 系统代理（127.0.0.1:7897） | 手动配置 |

### 阶段 2：第一轮尝试 — Node.js + Bybit API

**尝试方案**：Node.js Express 服务器 + Bybit 现货行情 API + CoinGecko 辅助

**步骤**：

1. 创建 `package.json`，安装 `express` 依赖
2. 编写 `server.js`，包含：
   - `/` → 托管静态 `index.html`
   - `/api/tickers` → 代理 Bybit API `/v5/market/tickers`
   - `/api/coins` → 代理 CoinGecko `/coins/markets`
3. 编写 `index.html`，前端通过 `fetch('/api/tickers')` 获取数据

**遇到的错误（按顺序）**：

| # | 错误 | 原因 |
|---|---|---|
| 1 | `'HTTPS_PROXY' 环境变量不工作` | Node.js 原生 `fetch` **不读取** `HTTPS_PROXY` 环境变量（这是 Node.js 已知行为，原因：`undici` 库默认不检查代理变量） |
| 2 | 尝试 `global-agent` npm 包 | `global-agent` 需要 `bootstrap()` 显式调用，且对 ESM 模块支持不完善 |
| 3 | 尝试 `proxy-agent` + `fetch` | 代理连接超时 30s+ |

**解决方案尝试**：设置 `HTTPS_PROXY=http://127.0.0.1:7897` 环境变量

```bash
set HTTPS_PROXY=http://127.0.0.1:7897
set HTTP_PROXY=http://127.0.0.1:7897
node server.js
```

**结果**：❌ 失败 — Node.js `fetch` 继续直接连接超时

**弃用 Node.js 的原因**：在 Windows 上，Node.js 的 HTTP 客户端（包括 `undici`、`node-fetch`、`axios`）默认不兼容 Windows 系统代理设置，需要手动配置代理库。而这会增加依赖复杂度和出错概率。

### 阶段 3：第二轮尝试 — 纯静态 + 浏览器直连 CoinGecko

**方案**：用 Python 的 `python -m http.server 3000` 作为静态文件服务器，浏览器端 JS 直接 `fetch('https://api.coingecko.com/...')`

**步骤**：

1. 删掉 `node_modules`、`package.json`、`server.js`
2. 用 `python -m http.server 3000` 替代 Node.js
3. 修改 `index.html` 的 JS 直接请求 CoinGecko

**验证结果**：

- ✅ 页面加载成功（HTTP 200）
- 浏览器显示 "⚡ 加载中..."
- ❌ 然后卡死，最终超时为空白页面

**原因分析**：
- Python `http.server` 是纯文件服务器，不提供任何代理功能
- 浏览器从 localhost:3000 加载页面 → 同源策略允许 fetch 外部 API（CORS）
- 但浏览器必须直接连接 `api.coingecko.com` → 在网络层面被墙（需要代理）
- 虽然系统代理已配置，但某些浏览器/场景下 localhost 来源的 fetch 不走代理

**关键发现**：PowerShell 的 `Invoke-WebRequest` **能成功** 访问 CoinGecko（走系统代理），但浏览器的同源 fetch 在无代理的直连中失败。

### 阶段 4：第三轮尝试 — Python 代理服务器

**方案**：写一个 Python 服务器，既托管静态文件又代理 CoinGecko 请求

**思路**：
- Python 的 `urllib` 默认使用环境变量 `HTTP_PROXY`/`HTTPS_PROXY`
- 如果能配置 Python 使用系统代理，就可以实现服务器端代理

**步骤**：

1. 编写 `server.py`，包含 `/api/data` 端点，该端点在 Python 端 `urllib.request.urlopen('https://api.coingecko.com/...')`
2. 尝试通过注册表读取 Windows 代理设置：

```python
import winreg
key = winreg.OpenKey(winreg.HKEY_CURRENT_USER,
    r'Software\Microsoft\Windows\CurrentVersion\Internet Settings')
enabled = winreg.QueryValueEx(key, 'ProxyEnable')[0]
server = winreg.QueryValueEx(key, 'ProxyServer')[0]
```

3. 使用 `urllib.request.ProxyHandler` 配置代理

**测试结果**：

- 服务器启动成功
- 连接 CoinGecko **超时**（超过 90 秒）
- 最终 Python 进程被强制终止

**失败原因**：

虽然在注册表中找到了代理地址 `127.0.0.1:7897`，但 Python 的 `urllib` 通过代理发起 HTTPS CONNECT 请求时，可能因为以下原因之一失败：

1. 代理本身对 Python 的 `urllib` 实现不兼容（代理软件可能只代理浏览器流量）
2. HTTPS CONNECT 通过 HTTP 代理需要额外握手，`urllib` 在这个环境下工作不正常
3. 代理需要认证（未配置）

**最终结论**：Python `urllib` 不能可靠地通过此代理访问 HTTPS 外部 API。

### 阶段 5：最终方案 — PowerShell 抓取 + Python 静态服务

**核心洞察**：

经过多轮测试，建立了以下可靠性与不可靠性矩阵：

| 客户端 | HTTPS 出站能力 | 原因 |
|---|---|---|
| PowerShell `Invoke-WebRequest` | ✅ 稳定 | 使用 .NET Framework，自动读取 Windows 系统代理 |
| 浏览器（Chrome/Edge） | ✅ 通常可靠 | 默认使用系统代理（但 localhost 页面可能例外） |
| Python `urllib` | ❌ 不可靠 | 不认系统代理，手动配置后仍有兼容问题 |
| Node.js `fetch` | ❌ 不可靠 | 不认系统代理环境变量 |

**最终架构决策**：

将数据获取和服务分离——谁行谁上：

```
数据获取 → PowerShell（唯一可靠的外部 HTTPS 客户端）
数据服务 → Python（纯本地文件读取，不出站）
```

**步骤**：

1. **创建 `fetch-data.ps1`**：PowerShell 脚本，通过系统代理访问 CoinGecko API，获取 250 个币的数据，转换为前端需要的格式，保存为 `data.json`
2. **重构 `server.py`**：去除所有代理逻辑，改为只读取本地 `data.json` 文件并返回
3. **修改 `index.html`**：JS 从 `fetch('/api/data')` 获取数据（同源请求，不需要 CORS，不需要代理）

**验证结果**：

```powershell
# 1. PowerShell 抓取
powershell -NoProfile -ExecutionPolicy Bypass -File fetch-data.ps1
# → Fetching from CoinGecko... Got 250 coins Saved data.json
# → data.json 约 90KB，250 条记录

# 2. Python 服务器
python server.py

# 3. 测试端点

```

### 阶段 6：start.bat 启动脚本问题

**问题**：最初的 `start.bat` 将整个 PowerShell 脚本内嵌在 `^` 续行符中

```batch
powershell -NoProfile -Command ^
  "$u='...';" ^
  "$r=Invoke-WebRequest..." ^
  ...
```

**错误症状**：

```bash
'live' 不是内部或外部命令
'order' 不是内部或外部命令
'per_page' 不是内部或外部命令
...
```

**原因**：`^` 续行符在 cmd.exe 中对带引号的参数处理不可靠，PowerShell 的命令行参数在分割时被错误解析，每个 URL 参数片段被当作独立命令执行。

**解决方案**：将 PowerShell 代码独立为 `fetch-data.ps1` 文件，`start.bat` 通过 `-File` 参数调用：

```batch
powershell -NoProfile -ExecutionPolicy Bypass -File fetch-data.ps1
```

**第二个问题**：`start.bat` 末尾的 `pause` 导致在非交互式终端中永久挂起（超时 130s）。

**原因**：`pause` 等待键盘输入，在自动化测试中永远不会返回。

**解决方案**：保留 `pause`（交互式使用需要），但在自动化测试中用 `cmd /c start.bat` + 后台进程管理。

### 5.3 fetch-data.ps1 — 数据抓取脚本

```powershell
# Tokenomics Screener - 数据抓取脚本
# 用法: powershell -NoProfile -ExecutionPolicy Bypass -File fetch-data.ps1

$url = "https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=250&page=1&sparkline=false&price_change_percentage=7d"

Write-Host "Fetching from CoinGecko..."
$r = Invoke-WebRequest -Uri $url -UseBasicParsing -TimeoutSec 30
$coins = $r.Content | ConvertFrom-Json
Write-Host "Got $($coins.Count) coins"

$transformed = $coins | ForEach-Object {
    $cr = $null
    if ($_.circulating_supply -and $_.total_supply -gt 0) {
        $cr = [double]$_.circulating_supply / [double]$_.total_supply
    }
    $star = if ($_.market_cap_rank) { [Math]::Max(1, 11 - [Math]::Min(10, $_.market_cap_rank)) } else { 0 }
    [PSCustomObject]@{
        symbol            = $_.symbol.ToUpper() + "USDT"
        name              = $_.name
        price             = if ($_.current_price) { [double]$_.current_price } else { 0 }
        market_cap        = if ($_.market_cap) { [double]$_.market_cap } else { $null }
        circulating_supply = if ($_.circulating_supply) { [double]$_.circulating_supply } else { $null }
        total_supply      = if ($_.total_supply) { [double]$_.total_supply } else { $null }
        circulating_ratio = $cr
        volume_24h_usdt   = if ($_.total_volume) { [double]$_.total_volume } else { 0 }
        percent_change_7d = if ($_.price_change_percentage_7d_in_currency) { [double]$_.price_change_percentage_7d_in_currency } else { $null }
        change_24h_pct    = if ($_.price_change_percentage_24h) { [double]$_.price_change_percentage_24h } else { $null }
        amplitude_24h_pct = if ($_.price_change_percentage_24h) { [double]$_.price_change_percentage_24h } else { $null }
        star_rating       = $star
        unlock_risk       = "Unknown"
        momentum_alert    = $false
    }
}

$ts = [long](Get-Date -UFormat %s) * 1000
$json = @{ ok = $true; data = $transformed; updated = $ts } | ConvertTo-Json -Depth 5 -Compress
[System.IO.File]::WriteAllText("$PSScriptRoot\data.json", $json)
Write-Host "Saved data.json"
```

**字段映射**（CoinGecko API → 前端）：

| 前端字段 | CoinGecko 字段 | 类型 | 说明 |
|---|---|---|---|
| `symbol` | `symbol + "USDT"` | string | 大写 + USDT 后缀 |
| `name` | `name` | string | 币种全名 |
| `price` | `current_price` | number | 当前价格 |
| `market_cap` | `market_cap` | number/null | 流通市值 |
| `circulating_supply` | `circulating_supply` | number/null | 流通供应量 |
| `total_supply` | `total_supply` | number/null | 总供应量 |
| `circulating_ratio` | 计算得出 | number/null | `circulating / total` |
| `volume_24h_usdt` | `total_volume` | number | 24h 交易量 |

### 5.4 server.py — Python 静态文件服务器

```python
"""Tokenomics Screener - 纯静态文件服务器
只读取本地 data.json，不出站请求
"""
import http.server
import json
import os

PORT = 3000
DIR = os.path.dirname(os.path.abspath(__file__))

class Handler(http.server.SimpleHTTPRequestHandler):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, directory=DIR, **kwargs)

    def do_GET(self):
        if self.path == '/api/data':
            return self.serve_data()
        return super().do_GET()

    def serve_data(self):
        data_path = os.path.join(DIR, 'data.json')
        if not os.path.exists(data_path):
            self.send_response(200)
            self.send_header('Content-Type', 'application/json')
            self.end_headers()
            self.wfile.write(json.dumps({'ok': False, 'error': 'data.json not found'}).encode())
            return
        with open(data_path, 'rb') as f:
            content = f.read()
        self.send_response(200)
        self.send_header('Content-Type', 'application/json')
        self.end_headers()
        self.wfile.write(content)

if __name__ == '__main__':
    os.chdir(DIR)
    server = http.server.HTTPServer(('0.0.0.0', PORT), Handler)
    print(f'Tokenomics Screener running at http://localhost:{PORT}')
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print('\nStopped.')
```

**关键设计决策**：

1. **不出站请求**：这是最重要的设计约束。服务器只从磁盘读取 `data.json`，不进行任何 HTTP 出站调用。这彻底规避了 Python 的代理问题。

2. **端口 3000**：与前端约定一致，避免端口冲突（3000 是开发服务器常用端口，通常未被占用）。

3. **`0.0.0.0`**：监听所有网络接口，允许局域网内其他设备访问（如手机测试）。

4. **没有 CORS 头**：因为前端从同源 `localhost:3000` 加载页面和 API 数据，不需要 CORS。

5. **二进制模式读取**：`open(data_path, 'rb')` 用于避免文本编码问题，直接返回原始 JSON。

## 7. 已知问题与局限性

### 7.1 功能性限制

| 问题 | 影响 | 优先级 |
|---|---|---|
| `amplitude_24h_pct` 与 `change_24h_pct` 使用相同数据 | 振幅应为（最高-最低）/开盘，当前误用涨跌幅 | 低 |
| `unlock_risk` 硬编码 "Unknown" | 未实现真实的代币解锁数据源 | 中 |
| `momentum_alert` 硬编码 false | 未实现动量检测逻辑 | 低 |
| CoinGecko 免费 API 限频 ~30 calls/min | 频繁刷新可能被限 | 低 |
| 每次启动需重新抓取数据 | 数据不会自动后台刷新 | 中 |

### 7.2 技术债务

| 问题 | 说明 |
|---|---|
| index.html 中文编码损坏 | 保存时编码问题导致中文显示为乱码，需要用编辑器重新保存（UTF-8 without BOM） |
| 数据通过全量 `innerHTML` 渲染 | 250 条以内性能可接受，更大数据集会卡顿 |
| 无错误日志 | `fetch-data.ps1` 没有写入错误日志文件 |
| Python 服务器单线程 | Python `http.server` 是同步单线程，同时请求多时会排队 |

### 7.3 网络限制

- **必须配置系统代理**才能访问 CoinGecko
- 代理地址硬编码在 Windows 系统设置中，非项目配置
- 如果代理不可用，`fetch-data.ps1` 会失败，但已有的 `data.json` 仍可正常使用
