## 五、评分规则（computeForwardScore）

```
+2  OI 30天分位 ≤ 0.30      （蓄水信号核心）
+2  距60天高点回撤 ≥ 30%     （底部区域）
+1  近5日平均振幅 < 5%       （波动压缩）
+1  OI 2M-30M               （小币区间）
+1  上线 ≤ 180 天            （新合约）
-3  额/OI ≥ 5               （事件日回避，验证B）
```

信号判定：
- 评分≥4 且环境向上 → `acc_candidate`（蓄水候选）
- 评分≥4 且环境向下 → `acc_candidate_env_bear`（候选但环境空）
- 额/OI≥5 → `avoid_event`（回避）
- 评分≥2 → `watch`（观察）
- 其他 → `noise`

- `openInterestHist` 权重 10/请求，只对 OI 2M-80M 候选拉取（4 并发 + 300ms 限速 ≈ 133 权重/s），避免触发 Binance 限流
