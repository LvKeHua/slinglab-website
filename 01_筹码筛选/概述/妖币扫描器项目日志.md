## 一、项目概览

在现有 **筹码筛选** (https://app.slinglab.xyz/screener/) 基础上，新增 **妖币扫描** Tab，基于 @derrrrrrrq 的成交量/OI 比方法论，实时筛选 Binance 合约中的挤压信号币种。

### 最终架构

```
GitHub Actions (US IP, 每5分钟)
  │
  ├─ relay.mjs ─→ Binance fAPI → 24h ticker + OI
  │                ├─ /api/relay-tickers  (筹码数据)
  │                └─ /api/relay-demon    (妖币数据)
  │
  ▼
Cloudflare Worker v8 (tokenomics-screener)
  │
  ├─ KV 存储 (TOKENOMICS_MARKET_DATA)
  │   ├─ market_data        → 711 coins (Binance/Bybit/OKX)
  │   ├─ market_updated      → 时间戳
  │   ├─ dashboard_html      → 前端页面 (50KB)
  │   ├─ demon_data          → 299 coins (Binance OI)
  │   ├─ demon_updated       → 时间戳
  │   └─ demon_count         → 数量
  │
  ├─ GET /api/tickers  → 筹码筛选数据
  ├─ GET /api/demon    → 妖币扫描数据
  ├─ GET /api/status   → 状态汇总
  └─ GET /             → 前端 HTML
```

## 二、关键决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 数据来源 | GitHub Actions relay | CF Worker 边缘 IP 被 Binance 403 封锁 |
| 前端框架 | 纯 CSS/JS，无 CDN | 中国用户 CDN 受限 |
| Worker 格式 | Service Worker (非 ES Module) | 兼容现有部署管线 |
| 密钥管理 | KV secret_text 绑定，multipart + `text` 属性 | CF API 新要求 |
| OI 数据 | Binance `/fapi/v1/openInterest` 并发 20 线程 | 单次拉取无批量接口 |
| vol/OI 阈值 | 默认 ≥10x，4 个预设 | @derrrrrrrq 方法论核心指标 |

## 六、注意事项

### OAuth Token 刷新

CF OAuth token 约 1 小时过期。刷新方法：

```bash
# 通过代理（浏览器 UA）刷新
curl -x http://127.0.0.1:7897 -A "Mozilla/5.0" \
  -d "grant_type=refresh_token&refresh_token=<REFRESH_TOKEN>" \
  "https://.cloudflare.com/client/v4/oauth/token" \
  -H "Content-Type: application/x-www-form-urlencoded"
```

刷新后更新 `~/.wrangler/config/default.toml`。

### 本地备份 Relay

如 GitHub Actions 不可用，可本地运行：
