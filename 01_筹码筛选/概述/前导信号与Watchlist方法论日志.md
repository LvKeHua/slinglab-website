# 前导信号与 Watchlist · 方法论日志

> 日期：2026-08-06
> 主题：如何通过历史数据提前把币纳入 watchlist，提前识别吸筹/派发
> 依据：@derrrrrrrq 705条推文 + SYN（Synapse）真实数据复盘
> 触发背景：现有妖币扫描器是"事件驱动"（vol/OI ≥ 10x 才亮灯），只能在暴涨/暴跌当天发现币

---

## 一、核心认知纠正：为什么现有扫描器看不到前兆

**换手高（vol/OI > 5）只出现在暴涨暴跌当天——这是事实，但换手是事件指标，不是前兆指标。**

现有妖币扫描器逻辑 = `vol/OI ≥ 10x` 才亮灯，等于"地震完才报警"。庄家拉升前一定有痕迹，但**不在"放量"维度，而在"有底仓的平静"里**。

derrrrrrrq 对吸筹期的原话（2026-04-09）：

> "观察了2周多吧，很多吸筹前期的变化是**价格涨的很缓慢的，oi和价格不会波动很剧烈**，前期是这样，**1小时的oi和价格可能都不会涨超过百分之1**，后面拉升挤压空头就是比较剧烈了，放量猛涨"

**结论**：要找的不是"大动作"，而是 **OI 有底仓 + 波动率压缩 + 价格缓涨**。低波动本身就是吸筹期最核心的特征——现有 vol/OI 筛选器恰好把这个信号当噪音滤掉了。

## 二、前兆信号体系（按数据可信度分层，全部可量化）

### 第 1 层：OI（核心，相对真实）

| OI 状态 | 含义 | 原文依据 |
|---|---|---|
| OI 底仓在 + 1h 波动 <1% + 价格缓涨 | **吸筹期** | "oi和价格不会波动很剧烈…1小时可能都不涨超过1%"（04-09） |
| OI 从高位被抽干到低水平 | **蓄水完成 = 挤压燃料备好** | "蓄水池被掏空到2月的低水平…1天的蓄水"（03-25，river 52M→16M 案例） |
| OI 低位企稳 + 负资费 + 底部盘整 | **挤压前夜** | "空单只有蓄水差不多，才有一轮大的挤压"（03-25） |
| OI 高位 + 量能萎缩 | **派发后期**（排除信号） | "oi维持在高位，但是交易量萎靡"（05-10） |
| OI↓ + Price↑ | 去杠杆反弹，危险 | "不要在多头去杠杆的时候离场"（04-09） |

**阶段判断规则**：用绝对值区间 + 方向斜率（OI 从低位开始增长），不用"周增长率 >20%"阈值——推文从未出现过增长率概念（已在《小币筛选系统_审查报告.md》纠正过）。

### 第 2 层：价格结构（Wyckoff，日线/4h 级别）

derrrrrrrq 看日线的方法（2026-05-05），可自动化：

> "一般要起势都会**拉一根大阳线，然后盘整个1-2周，后面等价格达到底部后，而且几乎没有量了**，庄会再次拉升，来回这样去测盘"

| 规则 | 条件（量化） | 说明 |
|---|---|---|
| 大阳线后盘整 | 日涨幅 >15% → 随后 7-14 天横盘 | 进观察池 |
| 量能枯竭 | 日成交额萎缩到启动前 1/3 以下 | 二次拉升临近 |
| 底部企稳 | 距 60 天高点 -60% + 横盘 >10 天 | 配合 Spring/ST 手动确认 |
| Spring 候选 | 跌破前低后快速收回 | 规则标记，手动确认 |
| 下跌洗盘 | 阴跌而非横盘 | "很多庄币的洗盘过程其实是下跌洗盘，并不是大家理解的区间震荡吸筹，其实这种效果更好"（05-01） |

### 第 3 层：资费（辅助，强控盘期不可信）

- 蓄水期特征：**持续负资费**——"最近几天资费一直是负的而且一小时收一次"（03-31）
- 负资费加深 + OI 低位 = 空头燃料堆积（挤压条件之一）
- 强控盘中后期资费完全被操控——"强控盘的中后期，资费、基差、oi价格背离在这里真的没啥用"（04-17）
- **只做标签，不做独立信号**（现有项目已正确实现）

### 第 4 层：链上（最接近信息优势，门槛最高）

**定位：链上是"确认/加分"层，不是"发现"层。** 没有链上数据，用 OI+价格结构+量能+资费可做到 80% 的提前识别；链上让"可能"变成"确认"。

| 链上信号 | 作用 | 原文案例 |
|---|---|---|
| 筹码集中度/控盘率 | 判断有没有拉盘资格——筹码决定上限 | "筹码只收回70%，30%收不回来，这种盘子你敢拉10倍20倍？"（04-03） |
| 交易所净流入 | 操盘准备/出货预警（必须配 OI 方向） | "链上几十M转入交易所→空头比例大增→强烈挤压"（04-21） |
| 做市商地址识别 | 同一操盘手跨币复用 = 真实信息优势 | "找到做市商地址…去年上线币安时同时转移大量代币到 bybit/binance"（04-14） |
| 解锁/质押时间表 | 提前算出货压力位 | "为 river 做工具，多少资金什么时候进入、什么时候解锁都能提前算出来"（05-26） |

**工具链**（他原话推荐，04-07）：metasleuth（链路追踪，EVM 免费/SOL 付费）、oklink（老数据查询强）、debank（结构友好）。做好后让 AI 做 skill 自动打标签、汇总统计报告。

## 三、Watchlist 的正确结构：三层漏斗

"提前纳入 watchlist"不靠单一神奇指标，靠分层机制。**现有项目缺的是中间层"观察池 + 打标"。**

```
第 1 层 候选池（机器全量扫，679 币 × 5 分钟，全自动）
       条件：OI 2-30M + 上线 <6 个月 + 距高点跌幅 >50% + 波动率压缩 + 量能枯竭
       ↓ 命中 → 打"吸筹结构候选"标签
第 2 层 观察池（人工确认，几十个币）
       看日线结构（大阳线后盘整？底部企稳？）→ 有条件看链上（控盘率、净流入）
       → 确认后打标进 watchlist，记录【阶段判断 + 理由 + 日期】← 缺失的一层
第 3 层 触发层（规则告警，只在 watchlist 内跑）
       告警规则：OI 斜率拐头 / ST-Spring 结构 / 蓄水完成（OI低位+负资费+放量）/ 资费翻转
       → 只有触发才动手
```

**原文依据**：
- "每天睡前睡醒第一时间就是看下关注的妖币列表，看看到什么阶段了，有没有哪些便宜的筹码可以捡"（05-19）
- "在A服务里面有各种token的标签，比如吸筹标签，那B基于规则告警服务其实感知不到"（03-29）→ 标签服务与告警服务要打通
- **反面教材**："当时打标了4的吸筹待拉升……但是没有弄吸筹的突破告警，因为每天要做的事情有点多"——"2周后对应的行情来了"（03-29）→ **打标但不设告警 = 白打标**

## 五、落地改动清单（基于现有管道）

### 1. 补历史数据（最优先）

| 数据 | 来源 | 做法 |
|---|---|---|
| 日线 | Binance klines | 一次性补 60 天（OHLCV+turnover），每日增量 |
| OI 历史 | openInterestHist（仅回看 30 天）| **从今天起每日存快照**，60 天后有自有 OI 斜率数据 |
| 资费历史 | fundingRate?limit=1000 | 一次性拉全 + 每日增量 |
| KV 键 | `hist:{symbol}` | 日线数组 |

### 2. 加前导因子（全部可计算）

| 因子 | 定义 | 用途 |
|---|---|---|
| `vol_compress` | 24h 真实波幅的 30 天分位数（<25 = 压缩） | 吸筹识别 |
| `oi_slope_30d` | OI 美元值 30 天斜率方向（非周增长率阈值） | 蓄水/派发方向 |
| `bottom_distance` | 距 60 天高点跌幅 + 底部横盘天数 | 底部结构 |
| `fuel_score` | OI 低位 + 负资费天数 + 波动压缩，三因子加权 | 蓄水评分（候选池排序） |
| `structure_tag` | 大阳线后盘整 1-2 周 + 量能枯竭（规则标记） | 观察池候选 |
| Spring/ST | 跌破前低快速收回（规则标记，**手动确认**） | 触发确认 |

### 3. 加 watchlist 层（前端 + KV）

- 候选标签（机器）：`fuel_score` 高 → 自动标"蓄水候选"
- 打标（人工）：观察池点"进 watchlist"，**强制记录阶段判断 + 日期 + 理由**（对接交易日志模板）
- 告警（规则）：只对 watchlist 内币跑——OI 斜率拐头 / 放量 + OI 跟上 / 资费从深负收敛 / ST 结构出现

### 4. 链上（第二步再上）

1. **交易所净流入告警**（metasleuth/oklink 免费层，先做 ETH 链）
2. 控盘率估算
3. 做市商地址识别 + 跨币行为库

## 六、心法提醒（防止新系统变成新的"看图讲故事"）

1. **注意力逆向**："只是当前能大启动的妖币一定不是大家注意力集中的那个"（06-22）——watchlist 全是热门 = 筛选逻辑反了
2. **吸筹需要时间**：siren 横盘吸筹 2 周（04-16），bill 第二波要 6-8 个月吸筹（07-22）——没磨够时间的"吸筹标签"不可信
3. **术语不构成 edge**：OI 斜率、波动压缩、蓄水评分每个都要能指着具体数据回答"为什么"——术语空转检查（参照审查报告标准）
4. **路径依赖**：同一操盘手的多个币手法可复用（AKE/EVAA 一个庄前后脚起势，07-20）——但要先确认是同一操盘手（同秒异动/链上地址重叠）
5. **告警闭环**：打标不进告警 = 白打标（03-29 反面教材）

## 七、数据验证（2026-08-06 实测，530 个 Binance USDT 永续全市场）

> 验证方法：Binance fAPI 全量数据（530 合约 × 40 天日线 + 31 天 OI 历史 + 全量资费快照），事件研究法。两个测试：A=蓄水信号（8/1 时点选币，看 5 天 forward）；B=额/OI>5 事件（全窗口逐日，看 3 天 forward）。

### 验证 A：蓄水信号 → 后续 5 天收益（8/1 → 8/6）

| 分组 | n | 均值 | 中位数 | 胜率 | >+10% | <-10% |
|---|---|---|---|---|---|---|
| 全市场（基准） | 529 | +4.5% | +1.7% | 65.6% | 11.7% | 5.1% |
| OI 低位（分位≤30%） | 230 | +6.6% | +1.5% | 67.0% | 9.6% | 2.6% |
| **OI 低位 + 负资费** | 37 | **+14.9%** | +1.5% | 56.8% | 13.5% | 5.4% |
| OI 低位+企稳+底部+低波动（完整组合） | **0** | — | — | — | — | — |

**结果**：
- ✅ **OI 低位 + 负资费组合确实命中了大赢家**：SYN（8/1 OI 分位 8%，5 天 +55.7%）、HEI（+428%）、DODOX（+70%）、FIDA（+14%）都在这一组。
- ⚠️ **但均值被 HEI 一个币拉动**：去掉 HEI 后 36 个币均值只剩 +3.4%，中位数 +1.5%，胜率 56.8% 反而低于全市场 65.6%。**它是彩票池不是稳赚信号**——抓得到 HEI/SYN 这种 5 倍、50% 的，但多数币不涨。
- ❌ **方法论日志里的"完整组合"（OI 低位+企稳+底部+低波动）实际选出了 0 个币**——条件太严，SYN 自己都不满足（OI 未企稳 + 波动未压缩）。原组合定义作废，改用放宽版：**OI 低位 + 负资费**。
- ⚠️ 8/1→8/6 全市场本身 +4.5%（反弹期），基准偏多，信号超额要打折看。

### 验证 B：额/OI>5 事件 → 后续 3 天收益（全窗口逐日）

| 分组 | n | 均值 | 中位数 | 胜率 | >+10% | <-10% |
|---|---|---|---|---|---|---|
| 全市场（基准，19038 币日） | — | +0.1% | -0.5% | 45.8% | 6.7% | 6.5% |
| **额/OI>5 事件日** | 665 | **-1.9%** | -4.8% | 33.4% | 16.5% | 33.7% |
| └ OI 跟上（+2% 以上） | 338 | -1.0% | -4.4% | 32.8% | 16.9% | 34.3% |
| └ OI 减少（-2% 以上） | 237 | -4.0% | -5.9% | 31.2% | 14.8% | 35.0% |
| └ 事件日当日上涨 | 391 | -2.1% | — | 31.5% | 16.4% | 34.8% |
| └ 事件日当日下跌 | 274 | -1.8% | — | 36.1% | 16.8% | 32.1% |

**结果**：
- ✅ **"事件日追高是负 EV"得到强验证**：额/OI>5 当天进场，3 天平均 -1.9%，胜率 33%，1/3 概率 3 天内再跌 10%。
- ✅ **无论当日暴涨还是暴跌，事件后 3 天都是负收益**（-2.1% vs -1.8%）——这就是"换手高只出现在暴涨暴跌当天"的统计本质：换手爆发是结果，不是入场信号。
- ⚠️ **修正日志原话"OI↑+价↑=健康可追"**：OI 跟上只是"少亏"（-1.0% vs -4.0%），不是"能赚"。"OI↑+Price↑最舒服"指的是**拉升早期建仓**（低额/OI 时），不是事件日追高。

### 验证结论（诚实版）

| 方法论主张 | 验证结果 |
|---|---|
| 换手高只出现在暴涨/暴跌当天 | ✅ 证实（事件 665 个，后 3 天均值 -1.9%，胜率 33%） |
| 事件日追高 = 接盘 | ✅ 证实（均值 -1.9%，无论 OI 方向、当日涨跌） |
| OI 跟上 = 更健康 | ⚠️ 部分证实（少亏 3pp，但仍为负） |
| OI 低位 + 负资费 = 蓄水待拉升 | ⚠️ 部分证实（均值 +14.9% 但被 HEI 单币拉动，中位数 +1.5%，胜率低于基准） |
| 完整蓄水组合（底部+企稳+低波动） | ❌ 证伪（8/1 选出 0 个币，SYN 自己都不满足） |
| 前兆信号能把 SYN 提前 3-4 天纳入 watchlist | ✅ 证实（SYN 8/1 命中 OI 低位 8% 分位 + 负资费，5 天 +55.7%） |

**统计限制（必须承认）**：① OI 历史仅 30 天（Binance 限制），只测了 8/1→8/6 一个 forward 窗口；② 资费用 8/6 快照近似 8/1（premiumIndex 只有当前值，未回补历史资费）；③ 8/1-8/6 是市场反弹期，基准偏多；④ 单期样本，HEI 一个 +428% 对均值影响巨大。**结论方向可信（事件追高=负 EV 证据很强），但蓄水信号的选币能力需要更长时间窗和多期样本才能定论。**

## 八、三个月全市场验证（2026-08-06 实测，OKX 全量 421 永续 × 90 天 + Binance 100 天日线）
