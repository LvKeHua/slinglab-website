## 一、项目概述

RunnerXBT 是一个**交易学习工具**：从 Telegram 频道 `@RunnerXBT_Insights`（交易员 @runnerxbt 的帖子）自动抓取消息，将帖子与 BTC/ETH K 线图对齐展示，用于研究该交易员的交易思路。

### 核心功能
1. **帖子 ↔ K 线对齐**：每条消息关联到对应日期的 K 线，点击消息自动跳转并高亮
2. **三色信号分类**：🔴 交易信号 / 🟡 市场分析 / 🔵 闲聊（关键词自动分类）
3. **三层信息架构**：纯净 K 线 + 三色堆叠密度图 + 悬停摘要卡
4. **4H/1D 双时间框架**：BTC/ETH 切换
5. **24/7 自动更新**：GitHub Actions 每 10 分钟同步 TG + K 线 + 部署

## 二、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│  GitHub Actions (免费 24/7，每 10 分钟 cron)                  │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ ① TG 增量抓取 (Telethon, session 存 secret)           │  │
│  │ ② OKX K线更新 (Binance 在 Actions IP 被 403 封)        │  │
│  │ ③ merge_messages.py 合并新旧数据                       │  │
│  │ ④ build_v2.py 构建自包含 HTML                          │  │
│  │ ⑤ inject_v2 + ux2 + ux3 + ux4 注入全部 UX 功能         │  │
│  │ ⑥ Cloudflare Pages 部署 (永久 API Token)              │  │
│  │ ⑦ 数据推回仓库 (增量抓取基础)                           │  │
│  └───────────────────────────────────────────────────────┘  │
│                    ↓ 部署                                   │
│  Cloudflare Pages → https://app.slinglab.xyz/runnerxbt/     │
└─────────────────────────────────────────────────────────────┘
```

### 关键设计决策
| 决策 | 原因 |
|------|------|
| Binance → OKX | Binance 对 GitHub Actions 美国 IP 返回 403/451 |
| 数据嵌入 HTML | 单文件自包含，无需 API 后端，静态托管即可 |
| 永久 CF API Token | OAuth refresh token 单次使用 + IP 敏感，反复断链 |
| session 存 GitHub Secret | 公开仓库不泄露凭据（base64 编码，38KB < 48KB 限制） |
| 增量抓取 | 仓库已有全量数据，每次只拉新消息（3 秒完成） |

```bash

```

```bash

# 或网页: https://github.com/LvKeHua/runnerxbt-insights/actions
```

### 本地完整构建（如需）
```bash
python build_v2.py          # 构建
python inject_v2.py         # 注入 1
python inject_ux2.py        # 注入 2
python inject_ux3.py        # 注入 3
python inject_ux4.py        # 注入 4
# 部署请用 Actions（云端自动跑以上全部）
```

### 添加 MENTIONED 关注币
无需改代码——`MENTIONED_COINS` 在 relay 配置中管理（如需要联系维护者）。

### 恢复 TG 会话
session 失效时：运行 `python scraper/v11_telethon.py` 重新 QR 登录，然后重新 base64 存 secret：
```bash
base64 -w0 scraper/tg_session.session | gh secret set TG_SESSION_B64 --repo LvKeHua/runnerxbt-insights
```
